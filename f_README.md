# Interactive University Registration System

This is a terminal-based university registration system developed using Python and Object-Oriented Programming (OOP).

## Features

- View available courses
- Register for courses
- View registered schedule
- Print tuition bill
- Error handling

## OOP Concepts Used

- Abstraction
- Inheritance
- Encapsulation
- Polymorphism

## Files

- a_course.py
- b_practical_course.py
- c_theoritical_course.py
- d_student_schedule.py
- e_main.py

## Run the Project

```bash
python e_main.py
